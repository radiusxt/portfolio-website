# Overview

Built with Next.js and TypeScript together, the website produces a fast, modular and scalable foundation for showcasing my skills in both software development & photography. The interface is designed using an open-source framework, Once UI, known for its minimal, dynamic and futuristic user experience across desktop and mobile devices.

# Design

A matrix of stars drift underneath a void into free moving particles, not aggressively, but persistently. A reminder that everything you're looking at was built from reasoning, logic and intention. Nothing here is by accident. The code is simply the means to produce something great. However, the matrix isn't the main character but rather, the atmosphere. The navy blue bleeds into the black behind it and suddenly the screen stops feeling like a screen at all. It feels like depth, almost if you're looking through something, rather than at it. The colour palette could have been anything from optimism to power. Instead, I decided to embrace minimalism. Both black and white carry their weight and establish elegance and clarity. It immerses you by removing everything unnecessary to keep the spotlight on the content. Navy blue bridges between the two, producing authority and professionalism, even at an arm's length. Together they make a subtle argument, you don't need noise to make a strong impression. The strongest presence is often the one that says the least.

The animations aren't accidental decorations. They're not UI polish sprinkled over the surface to make things feel "modern" and "trendy". They're felt. An interactive component easing into view carries a different emotional weight than one that simply appears. That slight delay is intentional, like a grand entrance. Transitions between sections flow nicely with certainty to a new page with its distinct purpose. When motion feels natural, it becomes subconscious. You only feel what it leaves behind, the sense of liveliness.

# Challenges & Insights

Without prior experience in TypeScript, building a website with Next.js presented a compelling challenge in balancing strict architectural patterns with creative flexibility. One of the primary insights is the necessity of mastering server components. While they offer significant performance gains by reducing client-side JavaScript, they require a disciplined approach to state management when integrating interactive UI elements. AI-assisted/agentic coding has become strong enough where it can produce high quality code when the given prompt is detailed and concise. This freed up time to focus less on the technical side and to think more creatively about layout, styling, colours and accessibility.

Building client-side components presented a challenge with correctly managing and transitioning states while optimising performance to avoid unnecessary re-renders and reducing expensive computations through preprocessing. The Once UI framework transforms the development experience, ensuring design tokens and component props remain consistent across the entire application. It's 'smarter' versions of regular HTML components such as `Flex`, `Row` and `Heading` make positioning and customisation require less code for faster production. The final result is a highly maintainable, scalable codebase bridging the gap between high-fidelity design concepts to deployment-ready products.
