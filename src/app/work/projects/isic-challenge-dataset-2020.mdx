# Overview

Skin cancer is the most prevalent type of cancer. Melanoma, specifically, is responsible for 75% of skin cancer deaths, despite being the least common skin cancer. The American Cancer Society estimates over 100,000 new melanoma cases will be diagnosed in 2020. Based on estimates, almost 7,000 people will die from the disease. As with other cancers, early and accurate detection, potentially aided by data science, can make treatment more effective. Melanoma is a deadly disease, but if caught early, most melanomas can be cured with minor surgery. Image analysis tools automate the diagnosis of melanoma will improve dermatologists' diagnostic accuracy. Better detection of melanoma has the opportunity to positively impact millions of people.

# Architecture Design

The classifier follows a traditional Siamese Neural Network (SNN) that learns a similarity function over a direction prediction on whether an image is malignant or benign. During training, pairs of lesion images are generated dynamically, with positive pairs containing the same class and negative pairs containing different classes. Each image undergoes preprocessing, including standard augmentation techniques such as random flips and rotations to improve the model’s ability to generalize to variations in lesion size and appearance. The network is trained specifically to determine whether two input images belong to the same class by learning meaningful visual patterns and representations of lesions.

The architecture consists of 2 identical ResNet-34 models which share weights and process each image independently. Each branch produces a 512-dimensional feature embedding, L2-normalized to lie on the unit hypersphere. The embeddings from both images are compared by computing the absolute difference (element-wise) to quantify their learned representations. This difference vector is passed through a small fully connected classifier to output a similarity score, representing the probability the two lesions belong to the same class. Training is performed using binary cross-entropy loss, while model performance is evaluated using accuracy, precision, recall, F1-score and ROC AUC. The model achieving the highest validation F1-score is retained for final evaluation. As the classifier is operating in a medical scenario, recall is significantly more important than precision. A false negative (missed positive) will increase the risk of death due to delayed treatment.

# Tradeoffs & Decisions

A Siamese architecture was chosen because lesion images often exhibit significant variation in factors such as lighting conditions, image scale, and skin tone. By learning an embedding space where lesions from the same class are positioned closer together and lesions from different classes are pushed further apart, the model focuses on relative similarity rather than absolute visual appearance. This approach can be more robust than traditional classification methods when dealing with high intra-class variability. To further improve performance and training efficiency, a pre-trained ResNet-34 backbone was adopted. Transfer learning provides strong visual feature extraction capabilities from the outset, reducing both training time and data requirements compared to training a deep network from scratch. While larger backbones could potentially achieve slightly higher accuracy, they would incur increased computational and memory costs.

Training pairs are generated on-the-fly rather than being precomputed, creating a virtually unlimited number of image combinations and exposing the model to more diverse relationships between samples. This improves generalization but introduces a dependency on the quality and balance of the generated pairs. The similarity comparison stage uses the absolute difference between embeddings followed by a lightweight classifier head. This design is simple, computationally efficient, and produces easily interpretable similarity scores. Alternative approaches such as contrastive loss, triplet loss, or cosine similarity were considered, but a binary classification objective with a classifier head provided greater training stability and straightforward threshold selection. Finally, light augmentation and ImageNet normalization were applied to improve robustness to real-world image variations while ensuring compatibility with the pre-trained backbone's expected input distribution.

# Challenges & Insights

A key challenge in this project was the strong class imbalance of benign to malignant cases, making it difficult for the SNN to learn robust similarity representations without bias toward benign lesions. Designing effective image pairs was non-trivial as poor sampling strategies led to substantial overfitting on training data. This overfitting manifested as high training performance with limited generalisation to unseen samples required careful regularisation and dataset augmentation. In SNNs, a common loss function is contrastive loss, enforcing separation between similar and dissimilar pairs. It was preferred over triplet loss for its simpler pair-based formulation and more stable training behaviour under severe class imbalances. The project highlighted the importance of thoughtful pair construction (due to the significant class imbalance), loss function selection and data balancing when applying metric-learning approaches to medical imaging, taking into account the trade-offs between model complexity and interpretability in high-stakes diagnostic imaging.

# Outcomes

The SNN performed reasonably well with a total accuracy of 81% and provided applicable experience in batched training tasks on a GPU cluster. This project taught me how to deal with model overfitting which is very common with CNNs in early training. A next step for this project would be to develop it further for production use in a practical setting.
